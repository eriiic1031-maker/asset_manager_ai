# 🏷️ 자산관리 AI

현장·부서별 회사 자산을 **구매 → 운용 → 감가상각 → 처분**까지 한 곳에서 관리하는 웹 프로그램입니다.
엑셀로 흩어져 관리되던 자산대장을 결재 흐름이 있는 시스템으로 옮기는 것을 목표로 만들었습니다.

**🔗 데모: https://asset-manager-demo.streamlit.app** (체험용 예시 데이터가 자동으로 들어 있습니다)

## 주요 기능

| 단계 | 기능 |
|---|---|
| 현황 | 현장별 자산 개수·금액을 계정과목·자산구분·상태·내용연수·취득연도 기준으로 집계, 취득가/장부가 전환, 알림 센터 |
| 취득 | 구매요청 → **금액별 결재선**(현장책임자 → 자산관리자 → 임원) → 비교견적 → 발주 → **부분 입고** 검수 → 자산 등록·QR 태그, 현장별 **예산** 대비 집행률, **공급업체** 관리·납기 실적, 구매요청서·검수조서 PDF |
| 운용 | 현장 간 이동신청·인수확인, 인수인계, **공용 장비 대여**(예약 달력·중복 방지·반납), **점검·수리 계획과 이력**, 보증 만료 알림, **직원 퇴사 시 자산·라이선스 회수**, 일괄 수정, 첨부파일(사진·영수증) |
| 재물조사 | QR·바코드 스캔(USB 스캐너·**휴대폰 카메라**) → 미발견 자산은 **경위서 요청** 자동 발송 → 결과 보고서 |
| 회계 | 정액·정률 월할 감가상각, **자본적 지출**, **세무 기준 상각과 세무조정(상각부인액·시인부족액)**, 3년 상각비 예측, 고정자산명세서·결산 마감, **회계 분개(전표)** |
| 계약 | **소프트웨어 라이선스**(보유·배정·만료), **렌탈·리스** 계약(만료 알림·월 비용) |
| 처분 | 처분 대상 자동 선별(수리비 누계 포함) → **위원회 투표(정족수)** → 매각 **입찰·낙찰** → 집행(PC는 보안 파기 증빙) → 제적·처분손익, 처분결의서 PDF, 폐기 이력 18만 건 조회 |
| 분석·알림 | 현장·계정·연령 분석, 매일 아침 **메일·웹훅 알림 요약**(`notify.py`) |
| AI | 자연어 요청("노트북 2대 필요해")을 분석해 다른 현장 유휴 자산 재배치를 먼저 제안하고 신청서를 미리 채움 |
| 법인차량 | 차량목록 연동(구매 차량 → 자산, 렌트 → 렌탈 계약, 정비 → 수리 이력), 운행일지 월별 주행거리 |

**로그인 없이** 첫 화면에서 "누구로 사용할지" 고르면, 그 사람의 역할(관리자·임원·재무·현장책임자·현장담당·직원)에 따라 메뉴와 권한이 달라집니다.

## 기술 스택

- **Python 3.12**, **Streamlit** (화면), **SQLite** (저장소), **pandas**
- **openpyxl** (엑셀 가져오기·내보내기), **qrcode · Pillow** (QR 라벨 PDF)
- **Ollama** (로컬 LLM 자연어 분석, 없으면 규칙 기반으로 동작)
- **pytest · Streamlit AppTest · GitHub Actions** (자동 테스트)

## 만들면서 해결한 문제

1. **엑셀 저장소의 한계 → SQLite + 메모리 캐시**
   처음에는 엑셀 파일에 저장했지만, 자산이 20만 건이 되자 저장 한 번에 약 60초가 걸렸습니다.
   SQLite로 바꾸고 바뀐 행만 저장하도록 해서 화면 전환을 0.1~0.6초로 줄였고, 엑셀은 내보내기 기능으로 남겼습니다.
2. **18만 건 목록을 빠르게 보여 주기**
   목록은 1,000개씩 페이지로 나누고, 같은 조건의 필터·합계 결과는 캐시해 다시 그릴 때 바로 보이게 했습니다.
   엑셀 파일은 매 화면마다 만들지 않고 버튼을 눌렀을 때만 만듭니다.
3. **여러 사람이 동시에 결재할 때 덮어쓰기 방지**
   저장할 때 잠금 안에서 최신 상태를 다시 확인해, 이미 다른 사람이 처리한 건은 "이미 처리됨"으로 안내합니다.
4. **인터넷 서버의 시간대 문제**
   클라우드 서버는 UTC로 돌아 날짜가 하루 어긋나는 문제를 발견해, 모든 날짜·시각을 한국 시간으로 고정했습니다.
5. **보안 보강**
   엑셀·CSV 내보내기에서 수식 주입(`=HYPERLINK…`)을 막았습니다.

## 테스트

```bash
pip install pytest
pytest -q
```

감가상각·세무조정·분개 대차 일치, 금액별 결재선, 부분 입고, 대여 중복 방지, 퇴사 회수, 위원회 투표·입찰, 재물조사 경위서 요청 등
데이터 테스트와 **6개 역할 × 모든 메뉴**가 오류 없이 열리는지 확인하는 화면 테스트까지 100개가 넘습니다. GitHub에 올리면 Actions 탭에서 자동으로 실행됩니다.

## 실행 방법 (VS Code)

1. VS Code에서 `asset_manager` 폴더를 엽니다 (파일 → 폴더 열기).
2. 터미널(Ctrl + `)에서 가상환경을 만들고 패키지를 설치합니다.

   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

   macOS·Linux는 `source .venv/bin/activate`.
3. 실행합니다.

   ```powershell
   streamlit run app.py
   ```

   또는 **F5** (실행 및 디버그 → "자산관리 AI 실행"). 브라우저에서 http://localhost:8501 이 열립니다.
   법인차량 관리 프로그램과 동시에 켤 때는 `streamlit run app.py --server.port 8502`로 실행하세요.
4. 처음 실행하면 `data/자산관리.db`가 자동으로 만들어지고, 현장은 **본사·평택·동탄·탕정**으로 시작합니다.
   처음에는 사용자가 **'관리자' 한 명**만 있습니다. 골라서 들어간 뒤 ⚙️ 설정 → 👤 사용자·역할에서 사람을 추가하세요.
   둘러보려면 ⚙️ 설정 → 💾 데이터 → **예시 데이터 만들기**를 누르세요 (역할별 체험용 사용자 6명도 함께 만들어집니다).
   - 크게: 보유 자산 **2만 500개**, 폐기·매각·기증·경매·망실로 처분된 자산 **18만 개** (20~40초)
   - 작게: 보유 2,000개, 처분 10,000개 (몇 초). 공개 데모 서버는 자동으로 작게 만듭니다.
   - 모든 예시 자산 비고에 `[예시]`가 붙고, 실제 운영 전에 같은 곳에서 한 번에 삭제할 수 있습니다.

## 인터넷 데모로 올리기 (Streamlit Community Cloud)

GitHub 저장소를 https://share.streamlit.io 에 연결하고 Main file을 `app.py`로 지정하면 됩니다.
`packages.txt`가 한글 글꼴(나눔고딕)을 설치해 QR 라벨의 한글이 깨지지 않습니다.
데모 서버에서는 예시 데이터가 자동으로 들어가고, 메일·웹훅 설정은 숨겨집니다. 서버가 다시 시작되면 데이터는 처음 상태로 돌아갑니다.

## 데이터 (data/자산관리.db)

보유 자산 수만 개 + 폐기·처분 자산 수십만 개를 다루기 위해 **SQLite 파일 하나**(`data/자산관리.db`)에 저장합니다.
엑셀은 20만 행이면 저장 한 번에 1분 가까이 걸려, 결재 한 건마다 화면이 멈추기 때문입니다.

- 별도 설치가 필요 없습니다 (파이썬 기본 내장). 처음 실행하면 자동으로 만들어집니다.
- 엑셀이 필요하면 **설정 → 데이터 내보내기**에서 표(자산목록, 구매요청, 이동신청, 분실파손, 처분, 자산이력, 재물조사, 결산명세 …)를 골라 xlsx·CSV로 받습니다. 각 화면의 목록도 같은 방식으로 내보낼 수 있습니다.
  - 엑셀은 수십만 행이면 수십 초 걸리고, CSV는 몇 초면 됩니다. CSV도 엑셀에서 바로 열립니다(한글 깨짐 없음).
- **설정 → DB 백업 파일 만들기**로 전체를 한 파일로 백업합니다. 복원은 프로그램을 끈 뒤 백업 파일 이름을 `자산관리.db`로 바꿔 data 폴더에 덮어쓰면 됩니다.
- 이전 버전(엑셀 저장)으로 쓰던 `data/*.xlsx`가 있으면 처음 실행할 때 자동으로 DB로 옮겨 옵니다.
- 여러 사람이 동시에 써도 서로의 변경을 덮어쓰지 않도록, 저장할 때마다 최신 상태를 확인하고 바뀐 행만 저장합니다.
- 프로그램을 켠 뒤 첫 화면에서만 데이터를 메모리에 올리느라 몇 초 걸리고(20만 건 기준 약 5초), 그 뒤로는 바로바로 열립니다.

## 업무 흐름

| 단계 | 흐름 | 처리하는 사람 |
|---|---|---|
| 취득 | 구매요청(PR) → 타당성 승인 → 비교견적(2건 이상) → 업체 선정·발주 → 입고 검수(규격·수량·파손) → 자산대장 등록·QR 태그 발급 | 승인·견적·등록: 관리자 / 검수: 요청 현장 담당자 |
| 이동 | 이동신청 → 보내는 현장 승인 → 받는 현장 인수확인 → 자산 현장 변경 | 보내는 쪽·받는 쪽 담당자 (관리자도 가능) |
| 인수인계 | 같은 현장 안 사용자·부서·위치 변경 (입퇴사, 조직개편, 층간 이동) | 현장 담당자 |
| 분실·파손 | 경위서 접수 → 조사(고의·과실, 변상, 수리견적, 보험) → 수리 복귀 또는 망실 제적 | 신고: 담당자 / 조사·종결: 관리자 |
| 재물조사 | 조사 시작 → QR·바코드 스캔 또는 표에서 확인/미발견/유휴 체크 → 마감 시 유휴 자산 재배치 대상 전환 | 시작·마감: 관리자 / 확인: 담당자 |
| 감가상각 | 정액법·정률법 월할 상각, 결산월 기준 고정자산명세서, 결산 마감 | 관리자 |
| 처분 | 처분 검토 대상 자동 선별 → 처분 신청 → 불용품 판정 위원회 승인 → 집행(PC·저장장치는 보안 파기 증빙 필수) → 장부 제적·처분손익 | 승인·제적: 관리자 / 집행: 담당자 |
| 폐기·처분 이력 | 제적된 자산 목록(폐기·매각·기증·사내 경매·망실) — 연도·방법·현장·계정 필터, 연도별 추이, 방법·현장별 합계, 자산 이력과 처분 요청서 조회 | 관리자: 🗑 폐기·처분 자산 / 담당자: 🗑 처분 이력 탭(자기 현장) |

### 감가상각 기준
- 계정과목 기본값: 비품·공기구비품·차량운반구 5년 정률, 기계장치 8년 정률, 소프트웨어 5년 정액. 자산마다 바꿀 수 있습니다.
- 정률법 상각률은 세법 방식(잔존가치 5%, 5년이면 0.451)으로 계산하고, 내용연수가 끝나면 유형자산은 비망가액 1,000원을 남깁니다.
- 자본화 기준금액(기본 100만 원) 미만은 소모품으로 등록을 제안하며, 소모품은 취득 시 비용 처리되어 상각에서 빠집니다.

## 법인차량 관리 프로그램 연동

관리자 → ➕ 자산 등록 → 🚗 법인차량 연동에서 **차량목록 샘플 양식**을 내려받을 수 있습니다.
법인차량 관리 프로그램의 `차량목록.xlsx`와 같은 20개 열에 구매·렌트 예시 4대와 작성 안내 시트가 들어 있어, 그대로 채워 두 프로그램에서 함께 쓸 수 있습니다.

`차량목록.xlsx` 경로를 넣거나 파일을 올리면,
**구매 차량(임원용)** 을 `차량운반구` 자산으로 등록합니다. 다시 동기화하면 현장·사용자·상태(정비중 → 수리중)가 갱신됩니다.
렌트 차량은 회사 소유가 아니므로 자산대장에 넣지 않습니다.

## QR 코드

- 자산 상세 → 🏷️ QR 태그에서 라벨 PNG·PDF를, 자산대장에서 여러 개를 골라 **A4 라벨 PDF(2열×7행)** 를 내려받아 인쇄합니다.
- 기본적으로 QR에는 태그번호가 담겨 재물조사 화면의 스캔 칸(USB·블루투스 바코드 스캐너)에서 바로 쓰입니다.
- 휴대폰으로 찍어서 자산 화면을 열려면
  1. F5 실행 목록에서 "휴대폰 QR 스캔 허용"을 고르거나 `streamlit run app.py --server.address 0.0.0.0` 으로 실행
  2. 설정 → **QR 기본주소**에 `http://이PC의IP:8501` 입력 (IP는 `ipconfig`로 확인, 같은 Wi-Fi 필요)
  3. 라벨을 다시 출력하면 QR이 `…/?tag=태그번호` 주소가 되어, 찍으면 자산 정보·재물조사 확인·분실 신고 화면이 열립니다.

## AI 요청 (Ollama)

왼쪽 메뉴 🤖 AI 요청·신청서에 "다음주까지 노트북 2대 필요해, 한 대 180만원 정도" 처럼 적으면
요청 종류·품명·수량·단가·필요일·계정과목을 해석하고, **다른 현장의 유휴 자산을 먼저 찾아 재배치를 제안**한 뒤 구매요청서를 미리 채워 줍니다.
분실·파손("FUR-2024-0003 노트북을 잃어버렸어"), 처분("고장난 프로젝터 폐기") 요청도 해당 신청서로 연결됩니다.
Ollama 주소와 모델(기본 `qwen2.5vl:3b`, 법인차량 프로그램과 동일)은 설정에서 바꿉니다. Ollama가 꺼져 있으면 규칙 기반으로 분석합니다.

## 사용자와 권한 (로그인 없음)

- 비밀번호 없이 첫 화면에서 **누구로 사용할지** 고릅니다. 사이드바의 **사용자 바꾸기**로 언제든 다른 사람으로 바꿀 수 있습니다.
- 사람 목록은 ⚙️ 설정 → 👤 사용자·역할에서 관리합니다 (이름·역할·소속 현장·부서·위원 여부).

| 역할 | 할 수 있는 일 |
|---|---|
| 관리자 | 모든 메뉴 (자산 등록·결재·재물조사·처분·설정) |
| 임원 | 고액 구매 최종 결재, 대시보드·감가상각·예산·분석 열람 |
| 재무 | 감가상각·결산·세무조정, 회계 분개, 예산, 라이선스, 렌탈·리스, 공급업체, 분석 |
| 현장책임자 | 우리 현장 홈, 구매요청 1차 결재, 이동·검수·대여·재물조사·퇴사 회수 |
| 현장담당 | 현장책임자와 같고 구매 결재만 없음 |
| 직원 | 내 자산, 장비 대여 신청, 구매 요청, 분실·파손 신고 |

- '위원'으로 표시한 사람은 처분 신청에 투표하고, 찬성이 **위원회 정족수**(설정)에 이르면 승인됩니다.
- 구매 결재선은 금액으로 정해집니다: **결재 기준1** 미만 현장책임자, 기준2 미만 + 자산관리자, 그 이상 + 임원 (설정에서 변경).
- 사내망에서 쓰는 것을 전제로 한 방식이라, 외부에 공개할 때는 로그인을 따로 붙이는 것이 좋습니다.
