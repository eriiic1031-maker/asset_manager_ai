# 🏷️ 자산관리 AI

현장·부서별 자산을 취득부터 처분까지 관리하는 Streamlit 프로그램입니다.
법인차량 관리 AI와 같은 화면 구성(사이드바 메뉴, KPI 카드, 탭 현황표, 승인/반려 카드, 상세·편집 팝업, Ollama 자연어 요청)을 따릅니다.

## VS Code에서 실행하기

1. VS Code에서 `asset_manager` 폴더를 엽니다 (파일 → 폴더 열기).
2. 터미널(Ctrl + `)에서 가상환경을 만들고 패키지를 설치합니다.

   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

   macOS·Linux는 `source .venv/bin/activate`.
3. 실행합니다.

   ```powershell
   streamlit run app.py
   ```

   또는 **F5** (실행 및 디버그 → "자산관리 AI 실행"). 브라우저에서 http://localhost:8502 가 열립니다.
   법인차량 관리 프로그램(8501)과 동시에 띄울 수 있도록 포트를 8502로 정해 두었습니다 (`.streamlit/config.toml`).
4. 처음 실행하면 `data` 폴더와 엑셀 파일이 자동으로 만들어지고, 현장은 법인차량 프로그램과 같은 **본사·평택·동탄·탕정**으로 시작합니다.
   둘러보려면 관리자 페이지 → ⚙️ 설정 → **예시 데이터 만들기**를 누르세요 (20~40초).
   보유 자산 약 **2만 500개**(현장 4곳), 폐기·매각·기증·경매·망실로 처분된 자산 약 **18만 개**와 처분 요청서 약 3,800건,
   진행 중인 구매·이동·사고·처분 요청과 재물조사가 만들어집니다. 모든 예시 자산 비고에 `[예시]`가 붙고, 실제 운영 전에 같은 곳에서 한 번에 삭제할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 실행 파일. 사이드바 메뉴, 관리자 PIN, QR 스캔 화면 연결 |
| `admin.py` | 관리자 페이지 (대시보드, 자산대장, 자산 등록, 결재함, 재물조사, 감가상각·결산, 처분 검토·유휴, 폐기·처분 자산, 설정) |
| `user.py` | 현장 담당자 페이지 (AI 요청, 우리 현장 자산, 다른 현장 유휴 자산, 신청서, 신청 현황, 처분 이력, 재물조사) + QR 스캔 화면 |
| `workflow.py` | 관리자·담당자 공용 결재 카드, 처리 팝업, 신청서, 자산 상세 팝업, 재물조사 작업 화면, 폐기·처분 자산 목록 |
| `data.py` | SQLite 저장소·캐시, 감가상각 계산, 결재 흐름, 법인차량 연동, 엑셀 내보내기, 예시 데이터 |
| `ai.py` | Ollama 자연어 요청 분석 (꺼져 있으면 규칙 기반으로 분석) |
| `ui.py` | 공통 CSS, KPI 카드, 배지, QR 코드·라벨 PDF, 엑셀 내려받기 |

## 데이터 (data/자산관리.db)

보유 자산 수만 개 + 폐기·처분 자산 수십만 개를 다루기 위해 **SQLite 파일 하나**(`data/자산관리.db`)에 저장합니다.
엑셀은 20만 행이면 저장 한 번에 1분 가까이 걸려, 결재 한 건마다 화면이 멈추기 때문입니다.

- 별도 설치가 필요 없습니다 (파이썬 기본 내장). 처음 실행하면 자동으로 만들어집니다.
- 엑셀이 필요하면 **설정 → 데이터 내보내기**에서 표(자산목록, 구매요청, 이동신청, 분실파손, 처분, 자산이력, 재물조사, 결산명세 …)를 골라 xlsx·CSV로 받습니다. 각 화면의 목록도 같은 방식으로 내보낼 수 있습니다.
  - 엑셀은 수십만 행이면 수십 초 걸리고, CSV는 몇 초면 됩니다. CSV도 엑셀에서 바로 열립니다(한글 깨짐 없음).
- **설정 → DB 백업 파일 만들기**로 전체를 한 파일로 백업합니다. 복원은 프로그램을 끈 뒤 백업 파일 이름을 `자산관리.db`로 바꿔 data 폴더에 덮어쓰면 됩니다.
- 이전 버전(엑셀 저장)으로 쓰던 `data/*.xlsx`가 있으면 처음 실행할 때 자동으로 DB로 옮겨 옵니다.
- 여러 사람이 동시에 써도 서로의 변경을 덮어쓰지 않도록, 저장할 때마다 최신 상태를 확인하고 바뀐 행만 저장합니다.
- 프로그램을 켠 뒤 첫 화면에서만 데이터를 메모리에 올리느라 몇 초 걸리고(20만 건 기준 약 5초), 그 뒤로는 바로바로 열립니다.

## 업무 흐름

| 단계 | 흐름 | 처리하는 사람 |
|---|---|---|
| 취득 | 구매요청(PR) → 타당성 승인 → 비교견적(2건 이상) → 업체 선정·발주 → 입고 검수(규격·수량·파손) → 자산대장 등록·QR 태그 발급 | 승인·견적·등록: 관리자 / 검수: 요청 현장 담당자 |
| 이동 | 이동신청 → 보내는 현장 승인 → 받는 현장 인수확인 → 자산 현장 변경 | 보내는 쪽·받는 쪽 담당자 (관리자도 가능) |
| 인수인계 | 같은 현장 안 사용자·부서·위치 변경 (입퇴사, 조직개편, 층간 이동) | 현장 담당자 |
| 분실·파손 | 경위서 접수 → 조사(고의·과실, 변상, 수리견적, 보험) → 수리 복귀 또는 망실 제적 | 신고: 담당자 / 조사·종결: 관리자 |
| 재물조사 | 조사 시작 → QR·바코드 스캔 또는 표에서 확인/미발견/유휴 체크 → 마감 시 유휴 자산 재배치 대상 전환 | 시작·마감: 관리자 / 확인: 담당자 |
| 감가상각 | 정액법·정률법 월할 상각, 결산월 기준 고정자산명세서, 결산 마감 | 관리자 |
| 처분 | 처분 검토 대상 자동 선별 → 처분 신청 → 불용품 판정 위원회 승인 → 집행(PC·저장장치는 보안 파기 증빙 필수) → 장부 제적·처분손익 | 승인·제적: 관리자 / 집행: 담당자 |
| 폐기·처분 이력 | 제적된 자산 목록(폐기·매각·기증·사내 경매·망실) — 연도·방법·현장·계정 필터, 연도별 추이, 방법·현장별 합계, 자산 이력과 처분 요청서 조회 | 관리자: 🗑 폐기·처분 자산 / 담당자: 🗑 처분 이력 탭(자기 현장) |

### 감가상각 기준
- 계정과목 기본값: 비품·공기구비품·차량운반구 5년 정률, 기계장치 8년 정률, 소프트웨어 5년 정액. 자산마다 바꿀 수 있습니다.
- 정률법 상각률은 세법 방식(잔존가치 5%, 5년이면 0.451)으로 계산하고, 내용연수가 끝나면 유형자산은 비망가액 1,000원을 남깁니다.
- 자본화 기준금액(기본 100만 원) 미만은 소모품으로 등록을 제안하며, 소모품은 취득 시 비용 처리되어 상각에서 빠집니다.

## 법인차량 관리 프로그램 연동

관리자 → ➕ 자산 등록 → 🚗 법인차량 연동에서 **차량목록 샘플 양식**을 내려받을 수 있습니다.
법인차량 관리 프로그램의 `차량목록.xlsx`와 같은 20개 열에 구매·렌트 예시 4대와 작성 안내 시트가 들어 있어, 그대로 채워 두 프로그램에서 함께 쓸 수 있습니다.

`차량목록.xlsx` 경로를 넣거나 파일을 올리면,
**구매 차량(임원용)** 을 `차량운반구` 자산으로 등록합니다. 다시 동기화하면 현장·사용자·상태(정비중 → 수리중)가 갱신됩니다.
렌트 차량은 회사 소유가 아니므로 자산대장에 넣지 않습니다.

## QR 코드

- 자산 상세 → 🏷️ QR 태그에서 라벨 PNG·PDF를, 자산대장에서 여러 개를 골라 **A4 라벨 PDF(2열×7행)** 를 내려받아 인쇄합니다.
- 기본적으로 QR에는 태그번호가 담겨 재물조사 화면의 스캔 칸(USB·블루투스 바코드 스캐너)에서 바로 쓰입니다.
- 휴대폰으로 찍어서 자산 화면을 열려면
  1. F5 실행 목록에서 "휴대폰 QR 스캔 허용"을 고르거나 `streamlit run app.py --server.address 0.0.0.0` 으로 실행
  2. 설정 → **QR 기본주소**에 `http://이PC의IP:8502` 입력 (IP는 `ipconfig`로 확인, 같은 Wi-Fi 필요)
  3. 라벨을 다시 출력하면 QR이 `…/?tag=태그번호` 주소가 되어, 찍으면 자산 정보·재물조사 확인·분실 신고 화면이 열립니다.

## AI 요청 (Ollama)

현장 담당자 페이지 → 🤖 AI 요청에 "다음주까지 노트북 2대 필요해, 한 대 180만원 정도" 처럼 적으면
요청 종류·품명·수량·단가·필요일·계정과목을 해석하고, **다른 현장의 유휴 자산을 먼저 찾아 재배치를 제안**한 뒤 구매요청서를 미리 채워 줍니다.
분실·파손("FUR-2024-0003 노트북을 잃어버렸어"), 처분("고장난 프로젝터 폐기") 요청도 해당 신청서로 연결됩니다.
Ollama 주소와 모델(기본 `qwen2.5vl:3b`, 법인차량 프로그램과 동일)은 설정에서 바꿉니다. Ollama가 꺼져 있으면 규칙 기반으로 분석합니다.

## 권한

- 법인차량 관리 AI처럼 로그인 없이 **이름을 입력**해 사용합니다. 현장 담당자는 사이드바에서 담당 현장과 이름을 고릅니다.
- 관리자 페이지는 설정의 **관리자 PIN**을 넣으면 PIN을 알아야 들어갈 수 있습니다.
- 사내망에서 쓰는 것을 전제로 한 간단한 구분이라, 외부에 공개할 때는 별도 로그인이 필요합니다.
